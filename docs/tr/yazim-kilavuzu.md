# Yazı standardı

GuildGate belgeleri kısa, teknik ve doğrulanabilir olmalıdır.

- Public API adlarını, error code değerlerini ve contract sabitlerini çevirmeyin.
- Güvenlik davranışını yalnızca kaynak kod ve testlerle doğrulandığı ölçüde anlatın.
- “Her zaman güvenli” gibi mutlak ifadeler yerine gerçek sınırı ve tüketicinin sorumluluğunu yazın.
- Güncel kararlı sürüm ile tarihsel migration örneklerini ayırın.
- Türkçe ve İngilizce sayfaların teknik anlamını eşit tutun.
- Kod örneklerini yayımlanan export yollarıyla çalıştırın ve örnekte secret kullanmayın.
- Sürüm notlarında yalnızca kullanıcıyı etkileyen davranış, uyumluluk, migration ve doğrulama sonuçlarını yazın.
